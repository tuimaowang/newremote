FSRemote 公网通信 Demo（Windows x64）

把整个 NetworkDemo 文件夹复制到测试电脑；不能只复制 exe。不需要安装 Qt Creator。
当前预设：公网 112.26.74.220:62843 → 服务器 192.168.3.63:62843，TCP。
该映射来自用户提供的信息，是否实际生效需要下面的测试确认。

1. 在 192.168.3.63 服务器电脑上：
   右键 Allow-Demo-Port.cmd → 以管理员身份运行。
   此操作只放行这个 Demo 程序的 TCP 62843 端口，不关闭系统防火墙。
   双击 Start-Server.cmd，出现 LISTENING 后保持窗口打开。
   双击 Test-Local.cmd，确认出现 PASS。

2. 在同一局域网的另一台电脑上：
   双击 Test-LAN.cmd，确认出现 PASS。

3. 在真正的外网电脑上（例如连接手机热点并断开原来的有线网络）：
   双击 Test-Public.cmd，确认出现 PASS。
   客户端会建立三次连接，每次发送五条固定 PING 并校验 PONG。
   只在服务器所在局域网使用公网地址测试，不能代替此步骤。

4. 测试结束：
   关闭服务端窗口，或 Ctrl+C；服务端也会在 30 分钟后自动退出。
   右键 Remove-Demo-Port.cmd → 以管理员身份运行，移除测试放行规则。

排查顺序：
   Local 失败：查看服务端是否启动、是否端口占用。
   Local 成功而 LAN 失败：查看 Windows 防火墙、服务器 IP 和网络是否互通。
   LAN 成功而 Public 失败：查看 iKuai TCP 映射、映射目标地址和上级网络限制。
   将 logs 文件夹里的 Server 和对应测试日志提供给开发者即可，不需要路由器密码。

这是短时使用的明文 WebSocket 连通性探针，只接收固定测试指令；无账号、令牌、
聊天、文件传输或命令执行功能。PASS 只证明此次测试链路双向收发成功。
服务端先推送固定问候，客户端核对后发送 PING，服务端回复 PONG。
每条连接最长 15 秒；同时最多 8 个已接受连接；消息上限 256 字节。
此 Demo 不是最终产品服务端；身份认证、加密和业务协议另行实现。

如更换地址或端口，只需修改 endpoint.json。
